Логотипы лабораторий для режима «Шкала» (вкладка Услуги → Услуги, режим «Лаборатории»).

Как добавить логотип:
1) Положите файл сюда, в эту папку. Например:  kdl.png
   - Лучше квадратное изображение (1:1), PNG с прозрачным фоном.
   - Размер достаточно небольшой (например 64×64 или 128×128) — в кружке он ~20–24px.
2) Откройте frontend/src/pages/Statistics/components/Directories.js, найдите объект LAB_LOGOS
   и добавьте строку соответствия «название лаборатории → файл». Например:

     const LAB_LOGOS = {
       'kdl':      '/lab-logos/kdl.png',
       'гемотест': '/lab-logos/gemotest.png',
       'инвитро':  '/lab-logos/invitro.png',
     };

   Ключ — это название лаборатории так, как оно приходит из МИС (поле lab).
   Регистр и лишние пробелы не важны (сопоставление идёт по нормализованному виду).

Если для лаборатории нет соответствия в LAB_LOGOS или файл не найден —
в кружке автоматически останется буквенная аббревиатура (как было раньше).

Логотипы МЕДЦЕНТРОВ (клиник) — переключатели медцентров в разделе
«Реферальные бонусы»: вкладки «Сотрудники», «Услуги», «Направления».

Файлы кладутся сюда же. Соответствие «id медцентра → файл» задано в
frontend/src/pages/ReferralBonuses/components/ClinicLogo.js (объект CLINIC_LOGOS).
Если файла нет или он не загрузился — вместо логотипа рисуется цветной кружок
медцентра, поэтому пути можно прописывать заранее.
