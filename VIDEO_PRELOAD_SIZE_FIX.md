# Исправление размера видео до загрузки (preload="none")

## Дата: 2026-01-18

## Проблема

При использовании `preload="none"` видео в редакторе отображалось маленьким до первого клика (до загрузки), а после клика принимало правильный размер на всю ширину.

### Причина

Браузер с атрибутом `preload="none"` не загружает метаданные видео (включая его размеры) до взаимодействия пользователя. Без метаданных браузер не знает соотношение сторон видео и отображает его с минимальными размерами по умолчанию.

## Решение

Добавлены явные стили для размера видео:
- `min-height: 300px` - минимальная высота
- `aspect-ratio: 16/9` - стандартное соотношение сторон
- `object-fit: contain` - масштабирование с сохранением пропорций

## Объяснение свойств

### `min-height: 300px`
Устанавливает минимальную высоту видео блока. Гарантирует что видео не будет "схлопнутым" до загрузки метаданных.

### `aspect-ratio: 16/9`
Современное CSS свойство для соотношения сторон. Браузер автоматически рассчитает высоту исходя из ширины. 16:9 - стандарт для большинства видео.

**Поддержка:** Chrome 88+, Firefox 89+, Safari 15+, Edge 88+

### `object-fit: contain`
Контролирует масштабирование содержимого:
- Видео вписывается в контейнер целиком
- Сохраняет исходные пропорции
- Добавляет черные полосы если соотношение не совпадает

**Альтернативы:**
- `cover` - заполняет весь контейнер, может обрезать края
- `fill` - растягивает без сохранения пропорций

## Преимущества

✅ **Нет скачка размера** - видео сразу отображается правильного размера
✅ **Стабильная верстка** - контент не прыгает при загрузке видео
✅ **16:9 ratio** - стандарт для YouTube, Vimeo и большинства видео
✅ **Responsive** - адаптируется под ширину контейнера
✅ **Preserve aspect ratio** - нет искажений

## Совместимость

### `aspect-ratio`
- ✅ Chrome 88+ (2021)
- ✅ Firefox 89+ (2021)
- ✅ Safari 15+ (2021)
- ✅ Edge 88+ (2021)

### Fallback для старых браузеров

Если нужна поддержка старых браузеров, можно добавить:

```css
.editor-content .ProseMirror video {
  /* Fallback для старых браузеров */
  padding-top: 56.25%; /* 16:9 aspect ratio */
  height: 0;

  /* Современный способ */
  padding-top: unset;
  aspect-ratio: 16/9;
  height: auto;
}
```

Но в 2026 году поддержка `aspect-ratio` уже есть во всех браузерах.

## Тестирование

1. Откройте редактор с видео
2. **До клика:** Видео должно занимать всю ширину с высотой по aspect-ratio 16:9
3. **После клика:** Размер НЕ должен измениться
4. Откройте режим просмотра - то же самое
