## Как тестировать

### 1. Перезапустите backend

```bash
cd backend
npm restart
# или если используете nodemon - он перезапустится автоматически
```

### 2. Перезапустите frontend

```bash
cd frontend
npm start
# или если уже запущен - обновите страницу с Ctrl+Shift+R
```

### 3. Проверьте редактор курсов

1. Откройте http://localhost:3000/admin/courses
2. Редактируйте любой урок с видео (или создайте новый)
3. Добавьте несколько видео через кнопку "Загрузить видео" 📹

**Ожидаемое поведение:**
- ✅ Редактор открывается мгновенно (без зависаний)
- ✅ Видео показывают серый placeholder с иконкой Play ▶️
- ✅ При клике на Play видео загружается и воспроизводится
- ✅ Нет ошибок в консоли

### 4. Проверьте просмотр курса

1. Откройте любой курс с видео
2. Просмотрите урок с видео

**Ожидаемое поведение:**

## Если возникли проблемы

### Видео не отображается

1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Жесткая перезагрузка страницы (Ctrl+Shift+R)
3. Проверьте консоль браузера (F12) на ошибки

### Ошибка "Unsupported MIME type"

1. Убедитесь, что backend перезапущен
2. Проверьте в DevTools → Network → выберите видео файл → Headers:
   - Should show: `Content-Type: video/mp4`
   - Should show: `Accept-Ranges: bytes`

### Placeholder не кликается

1. Проверьте, что импортирован правильный LocalVideo:
   ```javascript
   import { LocalVideo } from './LocalVideo';
   ```
2. Убедитесь, что в Editor.js LocalVideo добавлен в extensions
