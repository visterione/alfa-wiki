# Changelog: Search Highlight для страниц

## Описание

Реализована функциональность подсветки и автоскролла к найденному тексту на страницах при переходе из результатов поиска.

## Что изменено

### Backend (`backend/routes/search.js`)

1. **Строки 302-312**: Добавлен параметр `search` в URL для обычного поиска страниц
   ```javascript
   url: `/page/${page.slug}?search=${encodeURIComponent(searchTerm)}`
   ```

2. **Строки 509-519**: Добавлен параметр `search` в URL для fulltext поиска страниц
   ```javascript
   url: `/page/${r.slug}?search=${encodeURIComponent(searchTermLower)}`
   ```

### Frontend

#### `frontend/src/pages/PageView.js`

1. **Строка 2**: Добавлен импорт `useSearchParams` из react-router-dom
2. **Строка 13**: Добавлено использование `useSearchParams` для чтения параметра search из URL
3. **Строки 27-89**: Добавлена функция `highlightSearchText`:
   - Рекурсивно обходит DOM дерево
   - Находит все текстовые вхождения поискового запроса
   - Оборачивает их в `<mark class="search-highlight">`
   - Первое вхождение получает дополнительный класс `search-highlight-first`
   - Автоматически прокручивает к первому вхождению
4. **Строки 135-148**: В `contentRefCallback` добавлена логика:
   - Чтение параметра search из URL
   - Вызов функции подсветки с задержкой 500мс (для рендера контента)
   - Очистка параметра search из URL после использования

#### `frontend/src/pages/PageView.css`

**Строки 256-281**: Добавлены стили для подсветки:
- `.search-highlight` - базовый желтый фон (#fef08a)
- `.search-highlight-first` - более яркий желтый (#fde047) с анимацией пульсации
- `@keyframes highlight-pulse` - анимация привлечения внимания к первому вхождению

## Как работает

1. Пользователь вводит поисковый запрос в строку поиска
2. В результатах поиска показываются найденные страницы
3. При клике на страницу URL формируется как `/page/slug?search=query`
4. При загрузке страницы:
   - Контент рендерится
   - Через 500мс запускается функция подсветки
   - Все вхождения поискового запроса подсвечиваются желтым
   - Страница автоматически прокручивается к первому вхождению
   - Первое вхождение получает анимацию пульсации на 2 секунды
   - Параметр `search` удаляется из URL
