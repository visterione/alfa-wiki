# Функциональность Архива Аккредитаций

## Описание

Добавлена возможность перемещать записи аккредитаций в архив без их удаления. Архивные записи скрыты из основной таблицы, но доступны для просмотра на отдельной странице.

## Реализованный функционал

### 1. База данных
- **Новое поле**: `isArchived` (BOOLEAN, по умолчанию `false`)
- **Миграция**: `backend/migrations/add-accreditation-archived.sql`
- **Индекс**: Добавлен индекс на поле `isArchived` для быстрой фильтрации

### 2. Backend API

#### Новый роут: Архивирование записи
```
PATCH /api/accreditations/:id/archive
```
**Body:**
```json
{
  "isArchived": true  // или false для разархивирования
}
```

#### Обновленный роут: Получение записей
```
GET /api/accreditations?archived=true|false
```
- `archived=false` (по умолчанию) - только активные записи
- `archived=true` - только архивные записи

### 3. Frontend

#### Основная страница (`/accreditations`)
- **Новая кнопка**: "В архив" (фиолетовая) в столбце Действия
- **Ссылка**: "Архив" в правом верхнем углу для перехода к архиву
- **Фильтрация**: Автоматически показывает только неархивные записи
- **Функции**:
  - Просмотр записей
  - Редактирование
  - Прикрепление/удаление файлов
  - Перемещение в архив
  - Удаление

#### Страница архива (`/page/archive-accreditations`)
- **Новая страница**: `backend/bot/archive-accreditations.html`
- **Режим**: Только чтение (read-only)
- **Фильтрация**: Показывает только архивные записи
- **Кнопки действий**:
  - "Файлы" (просмотр и скачивание, без загрузки новых)
  - "Восстановить из архива" (зеленая кнопка)
  - "Удалить"
- **Ссылка**: "Назад к аккредитациям" для возврата

### 4. Особенности файлов в архиве
- Файлы можно просматривать и скачивать
- Нельзя загружать новые файлы
- Нельзя удалять существующие файлы
- При восстановлении записи все файлы остаются на месте

## Использование

### Перемещение записи в архив
1. На странице `/accreditations` найдите нужную запись
2. Нажмите кнопку "В архив" (фиолетовая иконка архива)
3. Подтвердите действие
4. Запись исчезнет из основной таблицы

### Просмотр архива
1. На странице `/page/accreditations` нажмите кнопку "Архив" в верхнем правом углу
2. Откроется страница `/page/archive-accreditations` со всеми архивными записями
3. Доступна фильтрация по медцентру, специальности и поиск

### Восстановление записи из архива
1. На странице `/page/archive-accreditations` найдите нужную запись
2. Нажмите кнопку "Восстановить из архива" (зеленая иконка)
3. Подтвердите действие
4. Запись вернется в основную таблицу

### Удаление записи из архива
1. На странице `/page/archive-accreditations` найдите нужную запись
2. Нажмите кнопку "Удалить" (красная иконка корзины)
3. Подтвердите действие
4. Запись будет удалена навсегда вместе со всеми файлами

## Установка

1. Запустите миграцию базы данных:
```bash
cd backend
psql -h localhost -U postgres -d alfa_wiki -f migrations/add-accreditation-archived.sql
```

2. Перезапустите сервер (изменения в моделях уже применены)

3. Обновите страницы в браузере (Ctrl+F5)

## Технические детали

### Модель (backend/models/index.js)
```javascript
isArchived: {
  type: DataTypes.BOOLEAN,
  defaultValue: false,
  comment: 'Запись перенесена в архив'
}
```

### API роут (backend/routes/accreditations.js)
```javascript
router.patch('/:id/archive', authenticate, async (req, res) => {
  const isArchived = req.body.isArchived !== undefined
    ? req.body.isArchived
    : !accreditation.isArchived;
  await accreditation.update({ isArchived });
  res.json(accreditation);
});
```

### Frontend функция (accreditations.html)
```javascript
function archiveRecord(id) {
  if (!confirm('Переместить запись в архив?')) return;
  fetchAPI(API_URL + '/' + id + '/archive', {
    method: 'PATCH',
    body: JSON.stringify({ isArchived: true })
  }).then(() => {
    showToast('Перенесено в архив', 'success');
    loadData();
  });
}
```

### Frontend функция (archive-accreditations.html)
```javascript
function restoreRecord(id) {
  if (!confirm('Восстановить запись из архива?')) return;
  fetchAPI(API_URL + '/' + id + '/archive', {
    method: 'PATCH',
    body: JSON.stringify({ isArchived: false })
  }).then(() => {
    showToast('Восстановлено из архива', 'success');
    loadData();
  });
}
```

## Примечания

- Архивные записи не участвуют в напоминаниях о истечении срока
- Поисковый индекс сохраняется для архивных записей
- При восстановлении запись сохраняет все свои данные и файлы
- Статистика на основной странице не учитывает архивные записи
