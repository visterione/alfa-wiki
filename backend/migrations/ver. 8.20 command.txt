Применение миграции ver. 8.20 (раздел «Вакансии» — второе поколение онбординга).

Из папки backend:

  npm run migrate:8.20:check     посмотреть план
  npm run migrate:8.20           применить

Миграция только создаёт десять таблиц vac_*. Таблицы onb_* старого онбординга не
трогаются, переноса данных между поколениями нет: процессы у них разные, и
старый модуль остаётся рабочим до отдельного релиза, который удалит его целиком.

После миграции отдельно нужно:

  npm run seed:vacancy-doctor    завести шаблон «Врач» по нынешней анкете

Шаблон заводится черновиком (isPublished = false), вакансий по нему не
создаётся — он нужен как готовый пример, на котором проверяется конструктор.
Повторный запуск ничего не перезаписывает.

Ещё одно: адрес QR-кода строится из MedCenter.code (латинский идентификатор
медцентра — alfa, kids и так далее). Поле необязательное, и у медцентров, где
собираются публиковать вакансии, оно должно быть заполнено — иначе ссылку не
на что повесить.
