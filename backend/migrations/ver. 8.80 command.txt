Применение миграции ver. 8.80 (свой сбор отзывов вместо GetLoyalty).

Из папки backend:

  npm run migrate:8.80:check     посмотреть, что уже на месте
  npm run migrate:8.80           применить

Что делает. Создаёт три таблицы — учётные записи площадок, места в них и
очередь задач для Альфа Парсера — и добавляет в reviews колонку sourceKey.
Существующие данные не меняются.

Перед применением. Пароли площадок шифруются ключом MAIL_SECRET_KEY — тем же,
что у почтовых ящиков. На бою он уже есть; без него учётную запись площадки
не сохранить.

После применения:

1. Перезапустить бэкенд — Sequelize должен увидеть таблицы.
2. Админка → Интеграции → новый ключ для парсера, право «Альфа Парсер: сбор
   отзывов и пароли площадок». В белый список IP вписать адрес сервера
   парсера: ключ открывает пароли всех площадок. Лимит запросов поднять до
   600 в минуту — первый проход по ПроДокторов идёт сотнями пачек.
3. Отзывы → Площадки: завести учётные записи. Места появятся после первой
   проверки парсером; каждое привязать к медцентру и включить «Сверку».
   GetLoyalty при этом продолжает работать как раньше.
