Применение миграции ver. 8.39 (удаление онбординга врача).

ПЕРЕД ЗАПУСКОМ СДЕЛАЙТЕ РЕЗЕРВНУЮ КОПИЮ БАЗЫ. Из папки backend:

  npm run backup

Затем:

  npm run migrate:8.39:check     посмотреть план
  npm run migrate:8.39           применить

Что делает. Удаляет восемь таблиц первого поколения онбординга (onb_*) вместе с
анкетами кандидатов, задачами, журналом и настройками чатов, и убирает из прав
пользователей ключ adminAccess.onboarding. Отменить нельзя — только
восстановлением базы из копии.

Что удалено в коде (уже в этом релизе): раздел «Онбординг врача» в вебе и в
мобильном приложении, публичная анкета /anketa, API /api/onboarding и
/api/public/v1/onboarding, крон сроков, переключатель права в карточке
пользователя.

Что сделать руками на сервере:

  rm -rf backend/uploads/onboarding

Это сканы дипломов и СНИЛС кандидатов первого поколения. Каталог
backend/uploads/onboarding-chats УДАЛЯТЬ НЕЛЬЗЯ: несмотря на имя, в нём лежат
аватарки рабочих чатов, которые показывает приветственное письмо «Вакансий».

Что сделать после выката: перезапустить бэкенд.

Чего ждать людям. Кнопка быстрого доступа «Онбординг врача» из панели пропала;
её место, цвет и знак (планшет с анкетой, бирюзовый) заняли «Вакансии» — раздел
для сотрудника не новый, а переехавший. В мобильном приложении вкладки найма
временно нет: раздел «Вакансии» в мобилку ещё не перенесён, задачи открываются
с компьютера. Уведомления о задачах приходят как и раньше — сообщением от
Ассистента и пушем.
