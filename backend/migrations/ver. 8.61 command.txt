Применение миграции ver. 8.61 (правила сортировки почтовых папок).

Из папки backend:

  npm run migrate:8.61:check     посмотреть состояние
  npm run migrate:8.61           применить

Миграция добавляет к папкам условия сортировки по отправителю, теме и наличию
вложений. После применения перезапустите backend.
