Применение миграции ver. 9.33 (вкладка «Счета» в админке открытой линии).

Из папки backend, ДО перезапуска портала — без таблиц вкладка не откроется,
а ночной обход кабинетов упадёт:

  npm run migrate:9.33:check     посмотреть, чего ещё нет
  npm run migrate:9.33           применить

Создаёт две таблицы: imobis_spend_days (расход по дням) и imobis_invoices
(счета текущей недели с PDF). Существующие данные не меняются.

Пароль кабинета шифруется ключом почтового модуля — в .env должен быть
MAIL_SECRET_KEY (заведён в 8.58; без него пароль не сохранится).

После перезапуска:
  1. Админка → Открытая линия → Рассылка → карточка медцентра → «Счёт у
     Имобиса»: вписать логин и пароль кабинета (ns……).
  2. Вкладка «Счета» → «Обновить»: первый обход заберёт расходы с начала
     прошлого месяца. Дальше — сам, в 05:30 каждый день и в 13:00 и 17:00 по
     будням (статусы оплаты).
