Применение миграции ver. 8.79 (почтовый клуб).

Из папки backend:

  npm run migrate:8.79:check     посмотреть, что уже на месте
  npm run migrate:8.79           применить

Что делает. Создаёт таблицу mail_club_subscribers — подписчиков рассылок,
которых присылают сайты медцентров. Ничего существующего не меняет, поэтому
резервная копия здесь обычная предосторожность, а не условие.

После применения:

1. Перезапустить бэкенд — Sequelize должен увидеть таблицу.
2. Админка → Интеграции → ключ сайта → «Изменить» → отметить «Почтовый клуб:
   запись подписчиков». Ключ не меняется, разработчику сайта передавать
   ничего, кроме PUBLIC_API_MAIL_CLUB.md, не нужно.
3. Проверить справочник медцентров: у каждой клиники, чей сайт будет слать
   подписки, в «ID в МИС» должен стоять её clinic_id. По нему API находит
   клуб; неизвестный clinic_id сайт получит ошибкой unknown_clinic, а не
   молчаливой записью «куда-нибудь».
