Применение миграции ver. 8.13 (самостоятельный раздел «Анонсы»).

Из папки backend:

  npm run migrate:8.13:check     посмотреть план
  npm run migrate:8.13           применить

Миграция добавляет расписание и шаблоны рассылок через ботов, расписание
почтовых рассылок и отдельное право adminAccess.announcements. Новое право
никому не выдаётся автоматически — его нужно включить в карточке пользователя.
