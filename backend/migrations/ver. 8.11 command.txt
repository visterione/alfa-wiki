Применение миграции ver. 8.11 (фактические шаблоны филиалов).

Из папки backend:

  npm run migrate:8.11:check     посмотреть план
  npm run migrate:8.11           применить

Миграция размножает существующие общие шаблоны по всем действующим филиалам,
которые принимают пациентов, затем удаляет общий уровень и запрещает создавать
шаблон без medCenterId.

Если у филиала уже есть собственные строки конкретного события, общий шаблон
этого события туда не копируется. Это защищает уже настроенный комплект от
неожиданного второго сообщения.

После применения на вкладке «Тексты» обязательно выбирается конкретный филиал.
Каждый текст Telegram, MAX и SMS сохраняется отдельно, поэтому в SMS можно
оставить свою сокращённую ссылку на карту.
