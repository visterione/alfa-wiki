Применение миграции ver. 8.12 (плейсхолдеры визита и блокировка врачей).

Из папки backend:

  npm run migrate:8.12:check     посмотреть план
  npm run migrate:8.12           применить

Миграция добавляет в снимок визита данные, необходимые расширенным
подстановкам: номер пациента, ID врача, окончание визита, дату создания
резерва, специальность, кабинет и реквизиты документа.

Список служебных врачей хранится в общей таблице settings под ключом
notif_blocked_doctors. После выбора врача новые события не ставятся в очередь,
а уже ожидающие уведомления дополнительно отсекаются перед самой отправкой.
