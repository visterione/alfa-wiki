Применение миграции ver. 7.85 (открытая линия).

Из папки backend:

  npm run migrate:7.85:check     посмотреть, чего ещё нет
  npm run migrate:7.85           применить

Миграция идемпотентна: всё через IF NOT EXISTS.

Что появляется: линии (omni_lines) с составом сотрудников и признаком смены
(omni_line_operators), обращения (omni_conversations) и переписка (omni_messages).
У ботов появляется ссылка на линию.

Пациент пользователем портала не становится намеренно: собеседник в обращении —
подписчик бота из bot_subscribers.

Отката нет намеренно: таблицы новые, старым ничего не мешают.
