Применение миграции ver. 8.50 (SMS уходит целиком на прямую отправку).

ПЕРЕД ЗАПУСКОМ СДЕЛАЙТЕ РЕЗЕРВНУЮ КОПИЮ БАЗЫ. Из папки backend:

  npm run backup

Затем:

  npm run migrate:8.50:check     посмотреть план
  npm run migrate:8.50           применить

Что делает. Ни одной колонки не добавляет и не удаляет — только вычищает имя
ступени «sms+webchat» из сохранённых настроек:
  settings / notif_cascade                 — общий каскад сети;
  notif_branch_settings."cascade"          — каскады филиалов;
  notif_templates."cascade"                — собственные каскады событий;
  тихие часы (сеть и филиалы)              — там ступень ЗАМЕНЯЕТСЯ на прямую.

Что это значит для людей. В настройке порядка доставки было две ступени SMS:
«SMS напрямую» через Имобис и «SMS» через Fromni. Разными каналами они не
были — то же сообщение тому же человеку на тот же номер. Теперь SMS в списке
одна, и называется она просто «SMS»: уточнение «напрямую» было нужно, только
пока рядом стояла вторая.

Осталась прямая — та, что через Имобис. Она отвечает, дошло ли сообщение:
отчёт о доставке приходит от провайдера, тогда как Fromni исход не сообщает
вовсе. Счёт у Имобиса заведён на каждый медцентр отдельно, поэтому и расход по
филиалам виден, а не размазан по общему договору агрегатора.

Fromni из каскада не уходит: ступень Notify остаётся на месте и работает как
работала.

НА ЧТО ПОСМОТРЕТЬ ПОСЛЕ ПРИМЕНЕНИЯ. Если у какого-то филиала SMS шла ТОЛЬКО
через Fromni, после миграции она у него не пойдёт никуда: своего токена Имобиса
у филиала может не быть. Проверьте в карточках филиалов (Администрирование →
Открытая линия → Филиалы), что токен и имя отправителя заполнены у всех, кому
SMS нужна. Филиал без токена SMS не отправляет — в журнале это видно строкой
«у филиала не задан свой токен Имобиса».

Тихие часы тронуты осознанно. Там, где ночью молчала SMS через Fromni, теперь
молчит прямая: список отвечает на вопрос «что ночью не отправляем», и просто
вычеркнуть оттуда SMS значило бы разрешить ночные SMS в сети, где их запретили
намеренно.

Историю миграция не трогает. В журнале отправок остаются записи вида
«notify+vk→sms+webchat» — так и было отправлено; расшифровка этого имени в
отчётах оставлена на месте.

Что сделать после выката: перезапустить бэкенд.
