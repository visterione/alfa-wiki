Применение миграции ver. 8.38 (возврат работы кандидату с шага проверки).

Из папки backend:

  npm run migrate:8.38:check     посмотреть план
  npm run migrate:8.38           применить

Что делает. Добавляет в vac_tasks одну колонку "returned" (JSONB). В ней лежат
замечания того, кто вернул работу: комментарий, отмеченные поля анкеты, кто и
когда вернул и какой это по счёту возврат. У задач, которые не возвращали,
колонка пустая — то есть до первого возврата ничего не меняется.

Зачем. Вернуть анкету умел только шаг решения и только пока процесс не начался.
Документы на трудоустройство кандидат присылает уже после согласования, и
юристу, который их проверяет, нужно то же самое: «вот это поправьте».

Что настроить после выката: в вакансии, на вкладке «Процесс», у шага проверки
документов выбрать «Может вернуть работу на шаг» → «Дозаполнение анкеты».
Без этой настройки ничего не меняется: кнопки «Вернуть» у задачи не будет.

Что сделать после выката: перезапустить бэкенд.
