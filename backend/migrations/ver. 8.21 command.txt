Применение миграции ver. 8.21 (раздел «Вакансии»: отказ от шаблонов).

Из папки backend:

  npm run migrate:8.21:check     посмотреть план
  npm run migrate:8.21           применить

Что делает. Анкета, процесс и тексты писем переезжают из шаблона в саму
вакансию; исполнители и рабочие чаты перецепляются с шаблона на вакансию;
таблица vac_templates удаляется. Пара флагов isOpen + isPublished заменена
одним полем status: draft / open / closed.

У каждой вакансии появляется publicCode — короткий код для прямой ссылки
(/vacancy/j/<код>). Филиальный QR по-прежнему ведёт на список вакансий
медцентра, прямой — сразу в конкретную анкету.

Данные не теряются: если шаблон был опубликован в нескольких филиалах, каждая
его вакансия получает свою копию анкеты и процесса и дальше живёт сама по себе.
Назначение на конкретный филиал достаётся только вакансии этого филиала.

Миграция идёт одной транзакцией — применяется целиком либо не применяется вовсе.

После неё сид врачебного шаблона больше не нужен и удалён: заводить анкету
теперь можно только вакансией.
