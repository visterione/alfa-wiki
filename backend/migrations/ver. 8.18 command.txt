Применение миграции ver. 8.18 (медцентр у выдачи из кассы).

Из папки backend:

  npm run migrate:8.18:check     посмотреть план
  npm run migrate:8.18           применить

Миграция добавляет cash_payments."clinicId". Старые выдачи остаются без
медцентра — проставить его нужно вручную в «Архив → Касса», после чего
сводка сама пересчитает остаток по каждому медцентру.
