Применение миграции ver. 9.09 (состав открытой линии по правилам).

Из папки backend:

  npm run migrate:9.09:check     посмотреть, чего ещё нет
  npm run migrate:9.09           применить

Создаёт таблицу omni_line_access_rules и колонку omni_line_operators."viaRule"
(по умолчанию false — все, кто уже в составе, считаются заведёнными руками и
правилами не трогаются).

Правил после миграции нет, состав линий не меняется. Заводятся они в
«Открытая линия и оповещения» → «Линии» → блок «Правила» у линии: роль,
медцентр или оба сразу (тогда это «И»). Правило сразу заводит в линию всех
подходящих сотрудников и открывает им раздел; дальше новые сотрудники попадают
в линию при сохранении их карточки, а переставшие подходить — уходят.

Проверить, кто в составе по правилам:

  SELECT l.name AS линия, u."displayName" AS сотрудник
  FROM omni_line_operators o
  JOIN omni_lines l ON l.id = o."lineId"
  JOIN users u ON u.id = o."userId"
  WHERE o."viaRule"
  ORDER BY 1, 2;
