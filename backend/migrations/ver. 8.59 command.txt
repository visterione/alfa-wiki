Применение миграции ver. 8.59 (групповой доступ к почте).

Из папки backend:

  npm run migrate:8.59:check     посмотреть состояние
  npm run migrate:8.59           применить

Миграция только добавляет таблицу правил группового доступа и индексы.
Существующие персональные доступы остаются без изменений.

Правило может содержать:

  - только медцентр — доступ всем сотрудникам медцентра;
  - только роль — доступ всем сотрудникам с этой ролью;
  - медцентр и роль — доступ только пересечению двух групп.

После применения перезапустите backend.
