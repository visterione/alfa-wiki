Применение миграции ver. 9.30 (правка, удаление и ответ с цитатой в открытой линии).

Из папки backend, ДО перезапуска портала и процесса забора обновлений
(npm run poller) — без новых колонок не откроется ни одна переписка:

  npm run migrate:9.30:check     посмотреть, чего ещё нет
  npm run migrate:9.30           применить

Добавляет в omni_messages пять колонок: "editedAt", "originalText",
"deletedAt", "deletedBy", "replyToId". Существующие сообщения не меняются.

Пользоваться: в переписке открытой линии — правая кнопка мыши по сообщению.
