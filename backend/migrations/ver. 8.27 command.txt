Применение миграции ver. 8.27 (непрочитанное в открытой линии).

Из папки backend:

  npm run migrate:8.27:check     посмотреть план
  npm run migrate:8.27           применить

Что делает. Добавляет omni_conversations."operatorReadAt" — докуда исполнитель
дочитал переписку. Непрочитанное в списке «Мои» считается по ней: входящие
позже отметки.

Засев. Всё, что сейчас взято в работу (status = 'assigned'), помечается
прочитанным на момент выката. Иначе в первый день у каждого оператора загорится
вся его переписка целиком. Очередь и архив не трогаются: ничьё обращение и так
помечено как новое, закрытое не читают.

Миграция идемпотентна: колонка добавляется с IF NOT EXISTS, засев ставит
отметку только там, где её нет. Повторный запуск безвреден.

ВАЖНО, кроме миграции. Вместе с этой версией открытая линия начинает работать
на событиях, а не на опросе, и входящие от ботов приходят из отдельного
процесса забора обновлений. Поэтому после выката надо перезапустить окно tmux
с messengerPoller — git pull его не обновляет, а он теперь сообщает порталу о
новом обращении. Без перезапуска всё продолжит работать, но новое обращение
будет появляться у оператора не сразу, а раз в полминуты.
