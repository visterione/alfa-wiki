Применение миграции ver. 9.23 (исключения из состава открытой линии).

Из папки backend, ДО перезапуска портала — без таблицы не откроются ни
настройки линий в админке, ни пересчёт состава по правилам:

  npm run migrate:9.23:check     посмотреть, чего ещё нет
  npm run migrate:9.23           применить

Создаёт таблицу omni_line_exclusions. Исключений после миграции нет, состав
линий не меняется. Исключают в «Открытая линия и оповещения» → «Линии» →
состав линии: у сотрудника, заведённого правилом, кнопка снятия теперь
исключает его. Вернуть — в блоке «Исключены» той же линии.

Кто исключён:

  SELECT l.name AS линия, u."displayName" AS сотрудник
  FROM omni_line_exclusions e
  JOIN omni_lines l ON l.id = e."lineId"
  JOIN users u ON u.id = e."userId"
  ORDER BY 1, 2;
