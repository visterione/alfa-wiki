# Почтовый клуб — запись подписчика

Блок «Почтовый клуб» на сайте клиники: посетитель оставляет адрес почты, сервер
сайта передаёт его нам, адрес попадает в список рассылки **этой клиники**.
У каждой клиники свой список, поэтому в каждом запросе передаётся `clinic_id`.

---

## Эндпоинт

```
POST https://wiki.medcentralfa.ru/api/public/v1/mail-club/subscribe
```

| Заголовок | Обяз. | Значение |
|---|---|---|
| `X-Api-Key` | да | API-ключ — тот же, которым отправляются анкеты |
| `Content-Type` | да | `application/json` |

Запрос отправляется **с сервера сайта**, а не из браузера: ключ секретный и не
должен попадать в код страницы.

---

## Поля

| Поле | Ключ | Обяз. | Формат |
|---|---|---|---|
| Электронная почта | `email` | да | обычный email, регистр не важен |
| ID клиники в МИС | `clinic_id` | да | число или строка с числом — тот же `clinic_id`, что в `/booking/duration` |
| Страница подписки | `page_url` | нет | адрес страницы с формой, до 500 символов |
| IP посетителя | `visitor_ip` | нет | до 64 символов |
| Браузер посетителя | `visitor_user_agent` | нет | заголовок `User-Agent` посетителя, до 400 символов |

`page_url`, `visitor_ip` и `visitor_user_agent` нам нужны, чтобы ответить
человеку на вопрос «откуда у вас мой адрес». IP и браузер посетителя знает
только сайт: запрос к нам приходит с вашего сервера, и его адрес — это адрес
сервера. Пожалуйста, передавайте их, если есть такая возможность.

Адрес записывается сразу, письма с подтверждением нет. Поэтому защита формы от
ботов (скрытое поле-ловушка, капча) — на стороне сайта.

---

## Какой `clinic_id` передавать

На каждом сайте — свой:

| `clinic_id` | Клиника |
|---|---|
| `1` | МЦ Проф |
| `2` | МЦ Альфа |
| `3` | МЦ Альфа Дети |
| `4` | МЦ 3К |
| `6` | МЦ Линия |
| `7` | МЦ Смайл |
| `11` | МЦ Сукко |
| `12` | Пункт забора анализов «Неолаб» |

Если список изменится, актуальный всегда можно получить запросом:

```
GET https://wiki.medcentralfa.ru/api/public/v1/mail-club/clinics
X-Api-Key: wk_live_...
```

```json
{
  "ok": true,
  "clinics": [
    { "clinic_id": "2", "name": "МЦ Альфа" },
    { "clinic_id": "4", "name": "МЦ 3К" }
  ]
}
```

---

## Пример

```bash
curl -X POST https://wiki.medcentralfa.ru/api/public/v1/mail-club/subscribe \
  -H "X-Api-Key: wk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "email": "ivanov@example.com",
    "clinic_id": 2,
    "page_url": "https://medcentralfa.ru/",
    "visitor_ip": "203.0.113.7",
    "visitor_user_agent": "Mozilla/5.0 ..."
  }'
```

---

## Ответы

**201** — новый подписчик:

```json
{ "ok": true, "status": "subscribed", "clinic": "МЦ Альфа" }
```

**200** — адрес уже был в клубе этой клиники (`already_subscribed`) или
когда-то отписался и теперь подписался снова (`resubscribed`):

```json
{ "ok": true, "status": "already_subscribed", "clinic": "МЦ Альфа" }
```

При 200 и 201 посетителю показывается одно и то же: «Спасибо, вы подписаны».
Повторная отправка того же адреса не создаёт дубль.

**400 `validation_failed`** — поле не заполнено или заполнено неверно:

```json
{
  "ok": false,
  "error": "validation_failed",
  "message": "Некоторые поля заполнены неверно",
  "fields": { "email": "«Электронная почта» — некорректный email" }
}
```

Текст из `fields.email` можно показать посетителю под полем.

**400 `unknown_clinic`** — такого `clinic_id` у нас нет. Это ошибка
настройки сайта, а не посетителя: сверьтесь со списком `/mail-club/clinics`.

```json
{ "ok": false, "error": "unknown_clinic", "message": "Клиники с clinic_id «99» у нас нет. ..." }
```

**401 / 403** — ключ не передан, неверен или ему не выдано право на почтовый
клуб. Напишите нам, если видите `scope_denied`.

**429 `rate_limited`** — слишком много запросов; повторите через число секунд
из заголовка `Retry-After`.

**500** — ошибка на нашей стороне. Адрес при этом не записан; посетителю
лучше предложить повторить попытку позже.
