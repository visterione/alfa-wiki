# Всплывающие уведомления для чата

## Что было добавлено

Реализованы всплывающие уведомления в стиле Telegram Desktop, которые появляются в правом нижнем углу при получении нового сообщения **на любой странице приложения**.

### Изменения в Backend

1. **Установлен Socket.IO** (`backend/package.json`)
   - Добавлена зависимость `socket.io`

2. **Настроен Socket.IO сервер** (`backend/server.js`)
   - Инициализирован Socket.IO с поддержкой CORS
   - Добавлена обработка подключений и комнат для пользователей
   - Сервер теперь использует `http.createServer()` вместо прямого `app.listen()`

3. **Добавлены real-time уведомления** (`backend/routes/chat.js`)
   - При отправке сообщения сервер отправляет событие `new_message` всем участникам чата (кроме отправителя)
   - Событие содержит информацию о сообщении и чате

### Изменения в Frontend

1. **Установлен Socket.IO Client** (`frontend/package.json`)
   - Добавлена зависимость `socket.io-client`

2. **Создан SocketContext** (`frontend/src/context/SocketContext.js`)
   - Глобальный контекст для управления Socket.IO подключением
   - Централизованное управление уведомлениями
   - Автоматическое подключение/отключение при входе/выходе пользователя
   - Звуковое уведомление при получении нового сообщения

3. **Создан компонент ChatNotification** (`frontend/src/components/ChatNotification.js`)
   - Красивое всплывающее уведомление с анимацией
   - Автоматически закрывается через 10 секунд (увеличено с 5 для удобства чтения)
   - Можно закрыть вручную или кликнуть для перехода к чату
   - Показывает аватар, имя чата и превью сообщения

4. **Стили для уведомлений** (`frontend/src/components/ChatNotification.css`)
   - Плавная анимация появления/исчезновения (slide-in/slide-out)
   - Поддержка темной темы
   - Адаптивный дизайн для мобильных устройств
   - Поддержка нескольких уведомлений одновременно

5. **Интеграция в Layout** (`frontend/src/components/Layout.js`)
   - Уведомления показываются на всех страницах приложения
   - Автоматически скрываются на странице Dashboard (там своя логика)
   - Клик по уведомлению переводит на страницу чата

6. **Интеграция Socket.IO в Dashboard** (`frontend/src/pages/Dashboard.js`)
   - Использует Socket из контекста
   - Обработка события `new_message` для обновления активного чата
   - Автоматическое обновление списка чатов и сообщений
   - Показ уведомлений только для неактивных чатов

7. **Обновлен App.js** (`frontend/src/App.js`)
   - Добавлен SocketProvider для глобального доступа к Socket.IO

## Как это работает

1. Когда пользователь отправляет сообщение, backend:
   - Сохраняет сообщение в базу данных
   - Отправляет Socket.IO событие `new_message` всем участникам чата (кроме отправителя)

2. Frontend получателя (через SocketContext):
   - Получает событие через Socket.IO на любой странице
   - Добавляет уведомление в глобальный список
   - Воспроизводит звуковой сигнал
   - Если пользователь на странице Dashboard с активным чатом - уведомление не показывается
   - На всех остальных страницах - показывается всплывающее уведомление

3. При клике на уведомление:
   - Уведомление закрывается
   - Если на другой странице - переход на страницу Dashboard
   - Если уже на Dashboard - открывается соответствующий чат

## Запуск

После установки зависимостей просто перезапустите backend и frontend:

```bash
# Backend
cd backend
npm start

# Frontend
cd frontend
npm start
```

## Особенности

- ✅ **Уведомления на всех страницах** - работают везде, не только на странице чата
- ✅ Real-time уведомления через WebSocket
- ✅ Fallback на polling (каждые 10 секунд)
- ✅ Красивая анимация в стиле Telegram
- ✅ Автоматическое закрытие через 10 секунд (достаточно времени для прочтения)
- ✅ Поддержка множественных уведомлений
- ✅ Клик для перехода к чату
- ✅ Показ аватара и превью сообщения
- ✅ Поддержка групповых и личных чатов
- ✅ Адаптивный дизайн
- ✅ Поддержка темной темы
- ✅ Звуковой сигнал при получении сообщения
- ✅ Умная фильтрация - не показывать для активного чата
- ✅ Централизованное управление через React Context
